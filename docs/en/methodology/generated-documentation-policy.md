# Generated Documentation Policy

> Canonical records drive views. Markdown is generated, never a second database.

## Rules

- `catalog/models/*.json`, `catalog/artifacts/*.json`,
  `catalog/manifest.json` are the source of truth (validated by JSON Schema
  where a schema exists).
- `catalog/views/**/*.md` and `catalog/views/**/*.json` carry generated
  markers (`GENERATED BY ATLAS CATALOG PIPELINE — DO NOT EDIT BY HAND`) and
  regeneration instructions (`atlas catalog views` / population pipeline).
- Same data produces EN (`index.en.md`) and AR (`index.ar.md`); no manual
  divergence. Technical tokens (GGUF, EXL2, AWQ, GPTQ, KV Cache, MoE, VRAM)
  stay English with Arabic explanation.
- Same input → same bytes (`sort_keys=True`, sorted ids, deterministic
  order) except documented `generated_at`.
- Never hand-edit generated files. Fix the generator or canonical data,
  then regenerate.
