# فهرس الأشكال

> المقابل الإنجليزي: [`README.md`](README.md)

## لماذا المخططات بالإنجليزية

جميع أشكال هذا المستودع مصوَّرة بالإنجليزية، وذلك قرار مقصود: تحمل المخططات
الهندسية كثافة عالية من المعرّفات وأسماء حقول المخططات وأسماء الحالات، وترجمة
هذه العناصر داخل المخطط نفسه تُضعف قراءته للجمهورين معًا.

ويحصل القارئ العربي على **شرح عربي وشرح إنجليزي** لكل شكل في هذا الفهرس، وعلى
الوثيقة التي تحمل الشكل نفسه.

كل مخطط مضمَّن في وثيقة Markdown بصيغة Mermaid أصلية، فيُعرض مباشرةً في
المستودع دون خطوة بناء أو أداة خارجية.

## ملاحظات العرض

تستخدم المخططات صيغة Mermaid وتُعرض مباشرةً على خادم المستودع. ولتصديرها إلى
SVG للاستخدام دون اتصال:

```bash
npm install -g @mermaid-js/mermaid-cli
mmdc -i input.md -o diagrams.svg
```

## لماذا لا نرسم الأشكال بالعربية؟

لا. الأشكال مرسومة بالإنجليزية في وثائقها، وهذا هو المقصود. أمّا الشرح على
مستوى كل شكل فيبقى بالعربية هنا، ولكن دون إعادة رسم المخطط نفسه بالعربية حتى لا
تفقد أسماء الحالات والمعرّفات دقّتها.
