# نظرة عامة على الكتالوج

> المقابل الإنجليزي: [`docs/en/catalog/catalog-overview.md`](../../en/catalog/catalog-overview.md)

## ما هو الكتالوج

الكتالوج هو مجموعة البيانات القانونية للأطلس القابلة للقراءة آليًا: مجموعة من سجلات
JSON مُحقَّقة ضد مخططات، تصف إصدارات النماذج ومُخرجاتها الفعلية، مع الأدلة
المرفقة بها، والعروض ثنائية اللغة المولَّدة من تلك الأدلة.

الكتالوج **ليس** مستودع أوزان. لا يحتوي هذا المستودع على أي أوزان نماذج.

وتُعاد أيّ من هذه الأرقام بالأوامر:

```bash

```

## بنية المجلدات

```text
catalog/
  manifest.json          الأعداد، ومعرّفات النماذج، وإصدارات المخططات
  models/                سجلات النماذج القانونية، ملف لكل إصدار
  artifacts/             سجلات المُخرجات القانونية، ملف لكل متغيّر مكمَّم
  sources/               سجل المصادر ورصد كل مصدر
  evidence/              مرافق الأدلة: حقل واحد، وقيمة واحدة، ومستوى واحد
  benchmarks/
    evaluations/         نتائج المقاييس بهوية أدوات كاملة
  measurements/          قياسات ذاكرة خارجية، لا تُنتج محليًا
  quality/
    profiles/            ملفات جودة متعددة المحاور لكل نموذج
    retention/           سجلات الاحتفاظ عند التكميم
    gaps.json            نطاقات الأدلة الناقصة لكل نموذج
    manifest.json        بيان لقطة الجودة
  closure/               مجموعة التوصيات الأساسية، وأدلة الذاكرة، والجاهزية
    external/            الأدلة الخارجية المُطبَّعة ونتائج المصادر
  snapshots/             لقطات المصدر الخام المحفوظة لإعادة التحقق
  views/                 العروض ثنائية اللغة المولَّدة بصيغتي Markdown وJSON
  refresh/               سجلات تشغيل متقلبة (غير منشورة)
  checkpoints/           نقاط تحقق الاكتشاف (غير منشورة)
  changes/               يوم التغييرات التشغيلي (غير منشورة)
```

## التغطية والانفتاح

يميّز الكتالوج بين حالات الانفتاح بدقة، ولا يستنتج حالة «مفتوح المصدر» من إمكانية
تنزيل الأوزان.

```text
open_source_ai / open_weights_permissive / open_weights_restricted
source_available / proprietary / unclear
```

توزيع الصيغ على الإصدارات المفهرسة:

| صيغة الحاوية | الإصدارات |
|---|---|
| GGUF | 12 |
| safetensors | 22 |

وتوزيع عائلات التكميم:

| العائلة | المُخرجات |
|---|---|
| q2 | 2 |
| q8 | 1 |
| bf16 | 5 |
| unknown | 26 |

 العدد الكبير في خانة `unknown` **بيانات صادقة، لا نقص في التقرير**: تلك الإصدارات
لا تصرّح بعائلة تكميم، ولا يستنتج الأطلس عائلةً من اسم ملف أو اسم مستودع.

## العروض المولَّدة

تُولَّد العروض من حمولة قانونية واحدة إلى اللغتين في العملية نفسها، فلا يمكن
للنسختين الإنجليزية والعربية أن تتباعدا.

| عائلة العرض | المحتوى |
|---|---|
| `4gb` و`8gb` و`12gb` و`16gb` | قوائم المرشَّحين لكل فئة |
| `quality/*` | عروض الجودة لكل محور، من العام إلى الاستخدام الوكيل للأدوات |
| `quality/tier-*` | توزيع جاهزية الجودة لكل فئة |
| `closure/core-set` | مجموعة التوصيات الأساسية مع حالات الجاهزية |
| `closure/tier-readiness` | مصفوفة الجاهزية لكل فئة والبوابات المعيقة |
| `closure/vram-evidence` | حالات أدلة الذاكرة لكل مرشّح أساسي |
| `closure/quant-retention` | إغلاق الاحتفاظ عند التكميم |
| `closure/evidence-gap` | مصفوفة فجوات الأدلة |
| `native-low-bit` و`ternary` و`high-compression` | عروض المتغيّرات الخاصة |
| `uncensored` و`abliterated` و`heretic` | عروض متغيّرات المحاذاة |

يحمل كل عرض لافتة تحذّر من التعديل اليدوي، وإعادة التوليد تُطمسه عمدًا.

## بيان التغطية الصادق

الكتالوج **مجموعة منتقاة**، لا فهرس كامل للنماذج المحلية. الحدود التالية بنيوية،
وتُبلَّغ ولا تُخفى:

- **ليس كل نموذج مفهرسًا.** يُبنى الكتالوج عبر مسارات اكتشاف مضبوطة، لا عبر حصر
  شامل.
- **تغطية الأدلة غير متساوية.** ثلاثة محاور جودة غير محلولة: الجودة العربية، وأدلة
  الملاءمة للذاكرة الرسومية، والجودة المستقلة متعددة المصادر. الجودة العربية
  `unknown` لكل الإصدارات الأربعة والثلاثين، كما تنقص أدلة الملاءمة وأدلة الجودة
  المستقلة لكل الإصدارات الأربعة والثلاثين.
- **صفر توصيات صارمة.** انظر [جاهزية التوصيات](../workflows/recommendation-readiness.md)
  للسبب، وللبوابات المعيقة مذكورةً بالاسم.
- **البنية غير محلولة لعشرة إصدارات**، مما يجعل بايتات ذاكرة KV غير قابلة للحساب
  لتلك المُخرجات، لا صفرًا.

## التحقق

تحقّق من أي سجل مقابل مخططه:

```bash
python -m atlas.validation.cli --schema model \
  --record catalog/models/openbmb-minicpm5-2b.json
```

أو عبر الأداة الرئيسية:

```bash
python -m atlas.cli.main validate --schema model \
  --record catalog/models/openbmb-minicpm5-2b.json
```
