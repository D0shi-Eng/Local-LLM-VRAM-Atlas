# جاهزية التوصيات

> المقابل الإنجليزي: [`docs/en/workflows/recommendation-readiness.md`](../../en/workflows/recommendation-readiness.md)
>
> المخططات معروضة في الوثيقة الإنجليزية عن قصد، لوضوح المصطلحات الهندسية.
> ولكل شكل شرح عربي في [فهرس الأشكال](../../diagrams/README.md).

## النطاق

تشرح هذه الوثيقة كيف يتحوّل مُخرَج مرشَّح إلى توصية لفئة ذاكرة معيّنة، أو كيف
يفشل في ذلك، وكيف يُبلِغ المستودع عن تلك النتيجة بصدق.

## معنى «الجاهزية»

لا ينشر الأطلس قائمة مرتَّبة بـ«أفضل النماذج». بل ينشر **حالة جاهزية** لكل مرشَّح
عند كل فئة، مشتقّة من بوابات معلَنة. الحالة فئوية، ولا تُدمج الفئات أبدًا.

| الحالة | المعنى |
|---|---|
| `STRICT_READY` | كل بوابة صارمة معلَنة مستوفاة بدليل محفوظ قابل للتنقّل. |
| `CANDIDATE_READY` | دليل جوهري ومحتوى مفيد، مع بقاء بوابة صارمة أو أكثر مفتوحة، وذكر كل بوابة ناقصة. |
| `CATALOG_ONLY` | محتوى فهرسة مشروع دون أدلة توصية كافية. |
| `BLOCKED` | مشكلة حرجة في الهوية أو الترخيص أو بيئة التشغيل أو النسب أو سلامة الأدلة. |

## معاني البوابات

| البوابة | أثر الإخفاق | سبب وجودها |
|---|---|---|
| `exact_artifact_identity` | `BLOCKED` | درجة أو حجم منسوب إلى «نموذج» لا يمكن إسناده إلى ملف محدَّد. |
| `current_provenance_persisted` | خفض الحالة | سجل لم يعد يصف المصدر لا يجوز نشره على أنه الحالي. |
| `license_status_acceptable` | `BLOCKED` | ترخيص غير واضح أو غير مقبول مشكلة حوكمة، لا فجوة دليل. |
| `runtime_compatibility_documented` | خفض الحالة | مُخرَج لم يوثَّق أحدٌ تشغيله ليس توصية. |
| `vram_fit_state_strict` | خفض الحالة | دون حدٍّ موثوق، فحكم «يناسب» تخمين. |
| `independent_multi_source_quality` | خفض الحالة | جدول ناشر واحد ليس تقييم جودة مستقلًا. |
| `no_unresolved_identity_conflict` | `BLOCKED` | الهوية المتناقضة تجعل كل رقم مشتقّ غير موثوق. |
| `quant_retention_when_post_training_quantized` | خفض الحالة | التكميم قد يكلّف جودة؛ وهذا الكلفة تُقاس ولا تُفترض. |
| `no_evidence_fabrication` | `BLOCKED` | البوابة الوحيدة التي لا يمكن التنازل عنها. |

**بوابةٌ واحدة ناقصة تخفض الحالة، ولا ترفعها أبدًا.**

## قواعد قاطعة

1. لا يُخفَّض أي عتبة سياسة ولا حالة مصنِّف ولا قاعدة فئة مصدر لإنتاج عدد غير
   صفري.
2. لا يوجد تجاوز يدوي، ولا تنازل بناءً على الشعبية أو العلامة التجارية أو الحداثة
   أو الحجم أو عدد المعاملات.
3. لا تُدمج الحالات، ولا يُمنح أي تنازل، ولا تُضبط يدويًا.
4. صفر توصيات صارمة نتيجة صحيحة قابلة للنشر.
5. عند غياب توصية صارمة، يقول المستودع ذلك ويسمّي البوابة المعيقة.

## الإشارات التي لا ترفع حالة أبدًا

```
downloads · likes · trending · parameter_count · artifact_byte_size
publisher_brand · release_recency · adoption
```
تُسجّل الشعبية بوصفها إشارة شعبية ولا غيرذاتها، ولا تُحوّل أبدًا إلى مقياس جودة، ولا تساهم في الأهلية، ولا تنتقل مقايسة الجودة بلطريقة معيارة.

## الوضع المُبلَّغ عنه حاليًا

يُبلِغ المستودع عن **صفر مرشَّح في حالة `STRICT_READY`** عند 4 و8 و12 و16 غيغابايت.
والبوابات المعيقة الغالبة هي `independent_multi_source_quality` و
`vram_fit_state_strict`، تليهما `quant_retention_when_post_training_quantized`.

هذا ليس حالة ناقصة تُصحَّح صامتًا في إصدار لاحق. بل هو الجواب الحالي
المستند إلى الأدلة، ويفضّله الأطلس على عدد غير صفري مُختلق. والأرقام الحيّة
تُولَّد بالأوامر:

```bash
python -m atlas.cli.main recommend tier --tier 8
python -m atlas.cli.main closure readiness
```
