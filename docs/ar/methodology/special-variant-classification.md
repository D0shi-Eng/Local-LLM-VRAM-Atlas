# تصنيف المتغيرات الخاصة (المرحلة 4)

> بالأدلة. لا ادعاءات جودة. غير مقيَّد ≠ أفضل.

## الضغط العالي

بأدلة منظمة فقط: BPW الفعّال، عائلة التكميم، بنية منخفضة البت الأصلية،
الصيغة المبلغ عنها/الموثقة. التكميم اللاحق العادي يبقى متميزًا عن منخفض
البت الأصلي والثلاثي الأصلي. انظر `src/atlas/catalog/special.py`.

## منخفض البت الأصلي

يتطلب دليل بنية التدريب (مثل بنية BitNet 1.58-bit المبلغ عنها). تكميم لاحق
1-2بت لا يُوسم أصليًا أبدًا.

## الثلاثي

ثلاثة مفاهيم منفصلة: `ternary-native`، التثليث اللاحق للتدريب، صيغة `TQ`.
اسم المستودع «Ternary» وحده ليس دليلًا.

## غير مقيَّد / مُزال القيود / Heretic

تُسجَّل كـ `variant_author_claim` مع المؤلف والنموذج الأساس والطريقة (أو
«الطريقة غير موثقة») وحالة التحقق. بقاء القدرات وسلوك الرفض يتطلبان أدلة
مستقلة مؤجلة لمراحل لاحقة. الشعبية (إعجابات/تنزيلات) ليست جودة أبدًا.
