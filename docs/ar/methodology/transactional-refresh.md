# التحديث المعاملاتي

التطبيق الصريح فقط. لا أمر فحص يغير الحالة المعيارية.

## البروتوكول

تجهيز → عرض الحالة المقترحة → تحقق مخطط → سلامة مراجع → عرض مولدة → تحقق
بيان → فحص اتساق شامل → استبدال ذري للملفات → حذف التجهيز. لقطات التراجع
تحفظ بايتات الملفات المتأثرة في مساحة مرحلية محلية (مسارات صريحة فقط، دون
نسخ واسع أو حذف عام). عند الفشل تُستعاد البايتات السابقة ولا تبقى مراجع
نصف مهاجرة.

الاستبدال الذري يعني أن لا قارئ يرى JSON ناقصًا.

## التعافي من التعطل

التشغيل المتقطع يترك علامة `catalog/refresh/.refresh-transaction.json`.
التشغيل التالي يكتشفها ويتعافى بأمان أو يرفض بتعليمات صريحة. لا تُتجاهل
العلامات النصف مطبقة بصمت.

## كتابة دنيا

البيانات والعروض العربية/الإنجليزية تُولد فقط عند تغير مصدرها فعليًا.
تصنيف VRAM يُعاد فقط للسجلات المتأثرة بتغير قطعة أو معمارية أو تكميم أو
منهجية ذات صلة. السجلات غير المتغيرة تبقى بايت-مستقرة. العروض باللغتين من
نفس البيانات المعيارية دون انحراف يدوي.

## ضوابط السلامة

حجم الملف ليس VRAM، والحد الأدنى وحده ليس ملاءمة، والمجهول ليس صفرًا، ونشط
MoE ليس مقيمًا، والمعمارية غير المدعومة لا تُقدّر. لا ترتيب ولا درجات ولا
توصيات؛ حداثة الاكتشاف ليست جودة.
