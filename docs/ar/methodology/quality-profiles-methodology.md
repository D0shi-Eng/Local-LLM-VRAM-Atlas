# منهجية ملفات الجودة

ملف الجودة عرض **متعدد المحاور** لإصدار نموذج واحد، يُبنى حتميًا من سجلات
التقييم المعيارية. لا ينشئ أطلس درجة جودة واحدة سحرية.

## لماذا لا درجة واحدة

الدرجة المفردة تخفي أي قدرة قِيست، وأي قياس أنتجها، وهل الدليل مستقل. كما
توحي بقابلية مقارنة بين محاور غير قابلة للمقارنة. لذلك تبقى قيم المحاور
منفصلة وقابلة للتتبع.

## المحاور المعلنة

| المحور | ما يملؤه (أمثلة) |
|---|---|
| `general_intelligence` | MMLU وARC وHellaSwag وPIQA وWinogrande |
| `reasoning` | GPQA وAIME وMATH-500 وBBH وGSM8K |
| `coding` | HumanEval وMBPP وLiveCodeBench وCodeforces وAider |
| `agentic_tool_use` | τ-bench وTerminal-Bench وSWE-bench |
| `instruction_following` | IFEval وMT-Bench وIFBench |
| `knowledge` | MMLU وTriviaQA وSimpleQA |
| `long_context` | AA-LCR وMLCR-AA وأطقم السياق الطويل المخصصة |
| `multilingual` | Global-MMLU-Lite وMGSM وC-Eval |
| `arabic` | تقييمات عربية خاصة فقط |
| `multimodal` | MMMU-Pro |
| `non_hallucination` | SimpleQA وأطقم الإخلاص |
| `safety_refusal_behavior` | تقييمات الرفض فقط |
| `professional_tasks` | أطقم مهنية مقنَّمة |

لا يُملأ محور إلا لقياسات لها ربط صريح في كود السياسة. ولا يعود إسناد المحور
إلى الشعبية أو الحجم أو اسم المستودع. ويوجد كل محور دائمًا في الملف، فإن لم
يوجد دليل فحالته `unknown` ولا `0` أبدًا.

## دعم القدرة ليس أداء القدرة

`tool_calling_supported = true` بيانات وصفية، أما **أداء** الأدوات فيحتاج تقييمًا
وكيليًا. وكذلك طول السياق المعلن ليس أداء سياق طويل، ولا يُقدَّم أداء عام على
أنه انخفاض في الهلوسة دون تقييم خاص بالهلوسة.

## الحتمية

معرّف الملف بصمة على معرّف النموذج ومجموعة معرّفات التقييم المطابقة مرتبة
وسياسة الإصدار. لا يدخل أي طابع زمني في هوية الملف، فينتج نفس اللقطة الأدلّة
نفس الملف دائمًا.

## حالة الدليل

يحمل كل ملف حالة دليل واحدة مشتقة من منشأ تقييماته المطابقة:
`independent_multi_source` أو `independent_single_source` أو
`verified_single_source` أو `publisher_only` أو `community_only` أو
`insufficient` أو `unknown`.

## `high_quality_candidate` محدَّدة بالسياسة

هذا المؤشر **ليس** نطاق جودة، ولا يعني شهرة ولا حجمًا ولا حداثة ولا أنه صادر
عن جهة رسمية.
يستلزم التأهيل دليل تقييم مطابقًا، ومحورًا واحدًا على الأقل بدليل قابل
للدفاع، وحالة دليل مستقلة، وعدم وجود تعارض هوية غير محسوم، وعدم وجود دليل
ملغى. كل قرار يحمل مبررًا مكتوبًا. نتيجة الكتالوج الحالي: لا يوجد نموذج
مؤهَّل، لأن كل نتيجة مسجلة صادرة عن الناشر.

## اختلاف المصادر

عندما يبلّغ مصدران عن قيمتين مختلفتين لنفس النموذج والقياس والإصدار والمقياس،
يكشف الملف ذلك الاختلاف كملاحظة على المحور. ولا تُنتقى النتائج الأعلى فقط.

## لا نطاق جودة

نطاقات الجودة بالحروف أو بالأرقام **غير منفَّذة** عمدًا، لأن النطاقات القابلة
للدفاع تتطلب مجموعة سكانية ممتلئة عبر مصادر، وهو غير متوفر في الكتالوج الحالي.
يبقى الترتيب داخل القياس الواحد متاحًا. ويُسجَّل هذا الرفض في سياسة نطاق
الجودة مع مبرره.
