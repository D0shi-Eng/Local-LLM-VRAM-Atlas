# منهجية فجوات الأدلة (المرحلة السادسة)

فجوات الأدلة **ميزة في الكتالوج** لا عيب. يبلّغ أطلس عمّا لا يعرفه كي لا
يُخلط الغياب بقوة ولا بضعف.

## فئات الفجوات المبلَّغ عنها

| الفئة | المعنى |
|---|---|
| `missing_independent_quality_evidence` | لا يوجد تقييم مستقل مرتبط |
| `missing_quant_retention_evidence` | أداة تكميم بلا قياس دقيق لنموذج مكمَّم |
| `missing_vram_fit_evidence` | لا فئة ذاكرة بحكم ملاءمة موثوق |
| `missing_runtime_evidence` | لا تلميح توافق لبيئة تشغيل والصيغة الحالية |
| `alignment_variant_unevaluated` | متغير محاذاة بلا دليل خاص به |
| `arabic_quality_unknown` | لا يوجد تقييم خاص بالعربية |
| `architecture_unresolved` | البنية غير معروفة، ما يمنع تقدير الذاكرة |
| `publisher_only_quality` | النتائج منشورة من الناشر فقط |

## فجوات الكتالوج الحالي (34 سجلًا)

- نقص أدلة جودة مستقلة: **34**
- نقص أدلة ملاءمة الذاكرة: **34** (23 `insufficient_evidence` و11 `unsupported`)
- نقص أدلة الاحتفاظ عند التكميم: **8**
- متغيرات محاذاة غير مُقيَّمة: **3**
- بنية غير محسومة: **10**
- جودة العربية غير معروفة: **34**
- جودة صادرة عن الناشر فقط: **3**

لا فجوة في أدلة بيئة التشغيل: لكل سجل في الكتالوج صيغة واحدة موثقة على الأقل
في بيئة تشغيل.

## كيف تُقرأ الفجوة

القياس الغائب يعني **غير مُقيَّم** لا فاشل. والنموذج المدرَج تحت
`missing_vram_fit_evidence` ليس سيئ الملاءمة للذاكرة، بل لا يستطيع أطلس إثبات
ملاءمة. ولا تُحوَّل أي فجوة إلى درجة صفر أو درجة سالبة أو تخفيض في تصنيف قائم.

## لماذا تُعرض الفجوات

إخفاء الفجوات يجعل كتالوجًا فارغًا يبدو ذا مصداقية. ويوجد تقرير الفجوات وأمر
`quality gaps` ليعرف القارئ الفرق بين «لا يوجد لدى أطلس دليل» و«وجد أطلس دليلًا
على مشكلة».

## طريق الإغلاق

لا تُغلق الفجوة إلا بدليل جديد وفق القواعد نفسها:

- تقييم مستقل بهوية نموذج مطابقة، أو
- حد علوي موثوق للذاكرة تحت ظروف موثقة، أو
- قياس دقيق لمتغير مكمَّم، أو
- تقييم عربي موثق.

وإغلاق الفجوة بالاستنتاج أو الشعبية أو الحجم أو السمعة غير مسموح.
