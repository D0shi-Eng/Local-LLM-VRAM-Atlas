# منهجية قابلية مقارنة المقاييس

لا تُقارَن نتيجتان إلا إذا تطابق كل ما يُغيِّر الرقم. وأي عنصر غير معروف
يمنع المقارنة بدل افتراض التساوي.

## مفتاح الإعداد القابل للمقارنة

| الحقل | سبب الأهمية |
|---|---|
| `benchmark_id` | المهام المختلفة قياسات مختلفة |
| `benchmark_version` | يتغير محتوى المهمة أو الموجّه أو التصنيف بين الإصدارات |
| `metric` | `pass@1` و`cons@64` والدقة مقاييس متمايزة |
| `score_unit` | النسبة ومقياس Elo ونقاط F1 ودرجات المحكّم غير متكافئة |
| `reasoning_mode` | نتائج وضع التفكير تختلف ماديًا عن غير التفكير |
| `tool_mode` | توفّر الأدوات يغيّر نتائج الأدوات والبرمجة |
| `prompting_mode` | وضع «صفر الأمثلة» ووضع «قليلة الأمثلة» إعدادان مختلفان |
| `context_configuration` | طول السياق يغيّر أداء السياق الطويل |

لا تُقارن نتيجة إصدار v1 مباشرة بإصدار v2 إلا إذا سمحت منهجية المصدر بذلك
صراحةً.

## دلالات المقياس محفوظة

الاتجاه صريح (`higher_is_better` / `lower_is_better`)، ولا يفترض أطلس أن
الأعلى أفضل أبدًا. تُحفظ نتيجة المصدر الخام ومقياسه دائمًا. وعند وجود قيمة
مُطبَّعة تُخزَّن إلى جانب `raw_score` و`raw_metric` و`normalization_formula`
و`normalization_version` ولا تحل محل قيمة المصدر.

مقياس Elo ليس دقة: لا تُقارَن قيمة Elo بنسبة مئوية. و`pass@1` و`pass@10`
مقياسان مختلفان لا يُدمجان. ولا تُفترض قابلية المقارنة بين تنفيذات مختلفة
لـ"accuracy" في أطر التقييم.

## الترتيب داخل القياس نفسه

يجوز لأطلس ترتيب النماذج داخل إعداد واحد محدد (القياس + الإصدار + الوضع)، لأن
النتائج قابلة للمقارنة وفق منهجية ذلك المصدر. تُحفظ النتيجة الخام والترتيب
وحجم المجتمع والمئين عند حسابه. المجتمع الذي يحتوي نتيجة واحدة لا ينتج ترتيبًا:
النتيجة الواحدة ليست ترتيبًا.

## قواعد المئين

المئين يحسبه أطلس ويُوثَّق على أنه كذلك:

- المجتمع = الإعداد القابل للمقارنة بدقّة فقط؛
- تتقاسم التعادات أفضل ترتيب محقق في ذلك المجتمع؛
- `percentile = (population - rank + 1) / population` والأعلى أفضل؛
- النتائج الناقصة أو الملغاة تُستبعد من المجتمع ولا تُحسب صفرًا؛
- لا يُنسب المئين إلى المصدر إلا إذا كان هو من ينشره.

## التطبيع عبر المقاييس

لا تُوسَّط خامًا نتائج MMLU أو نتائج البرمجة أو Elo أو `pass@k`. فالمقاييس
المختلفة تتطلب تطبيعًا صريحًا بإصدار موثّق، وأوزان مبرَّرة، ومعالجة اتجاه،
وتثبيت إصدارات المقاييس، ومعالجة واضحة للغياب. وحيث لا توجد صيغة قابلة
للدفاع **لا يُنشأ أي تجميع**، ويُسجَّل التجميع بحالة `refused` مع سببه.

## نسب المقاييس ومنع العد المزدوج

لا تُحتوى العملية ذاتها مرتين. فإذا تضمّن أحد leaderboards قياسًا يعرضه آخر
أيضًا، تُسجَّل العلاقة كنسق مقاييس لا كنتائج مستقلة. فالاستقلالية بعدد عمليات
التقييم الأصلية لا بعدد الروابط.

## الإلغاء والإحلال

عند إلغاء إصدار من قياس، يُحفظ السجل القديم ويُوسم `superseded` مع
`superseded_by` يشير إلى السجل الأحدث. لا تُعاد كتابة التاريخ، والنتيجة
المصحَّحة تصبح سجلًا إحلاليًا جديدًا.

## الحداثة

انقضاء الزمن وحده لا يُبطل نتيجة. الحداثة تُعبر بالإلغاء، وبتغيّر إطار
التقييم، وانزياح المراجعة. لا تعلن سياسة الحداثة أي مدة انتهاء اعتباطية.
