# دلالات نقاط التوقف (المرحلة الخامسة)

لا مؤشر عام واحد. نقطة لكل (مصدر اكتشاف، استراتيجية، ناشر/استعلام، مزود)
تحت `catalog/checkpoints/`.

كل نقطة: معرف الاستراتيجية والمصدر، المزود، آخر تشغيل ناجح، العلامة
المزودية (أحدث طابع مزود)، بداية التداخل (العلامة ناقص نافذة تداخل)، آخر
هوية ومراجعة، حالة استمرار، والحالة (سليم/جزئي/فاشل/محدد المعدل/نفدت
الميزانية).

القواعد:

- طوابع المزود حيث أمكن؛ الساعة المحلية ليست مرجعًا.
- لا يُتجاوز مرشح لمجرد أن طابعه قبل العلامة بثوانٍ (التداخل يمتص الانحراف).
- لا تتقدم العلامة قبل تطبيع المرشحين وإزالة تكرارهم ومعالجتهم أو تأجيلهم
  بأمان وحفظ الحالة — وإلا تخطى التعطل نماذج نهائيًا.
- المصدر الفاشل لا يتقدم؛ النجاح الجزئي يُسجل لكل مصدر.
- تقدم الاكتشاف وتطبيق الكتالوج مترابطان لا متطابقان: مرشح مكتشف ضاع بفشل
  تطبيق لا يُتجاوز (الطابور والاسترداد يعيدانه في التشغيل اليدوي التالي).
- طابور التأجيل حالة محفوظة لا خدمة: لا عملية تنتظر المهام؛ الاستدعاء اليدوي
  التالي يعالجه.
- جاهزية المجدول واجهة فقط: قد يشغل مجدول خارجي يومًا أمر تحديث واحدًا ثم
  يخرج برمز موثق. لا مجدول ولا مهمة ولا خدمة ولا عملية مقيمة في المرحلة
  الخامسة.
