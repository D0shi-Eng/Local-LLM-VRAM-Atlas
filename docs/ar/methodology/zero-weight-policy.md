# سياسة انعدام الأوزان (قاعدة معمارية دائمة)

> المقابل الإنجليزي: `docs/en/methodology/zero-weight-policy.md`

## القاعدة

أطلس VRAM للنماذج المحلية مستودع بلا أوزان. يخزن البيانات الوصفية والقوائم
ومراجع المصادر والمعرفات والمراجعات وأسماء الملفات وأحجام الملفات البعيدة
وبصماتها عند كشفها والتراخيص وحقائق البنية والتكميم ومعرفة توافق التشغيل
والرياضيات وأدلة القياس الخارجي والتوثيق. لا يخزن أبدًا حمولات أوزان GGUF أو
Safetensors أو EXL2 أو AWQ أو GPTQ أو MLX أو نقاط التفتيش — لا أجزاء ولا
تنزيلات جزئية ولا فحص رؤوس بالنطاقات.

## النتائج

يجب أن يحيل المستودع العام المستخدمين إلى المزودين الأصليين بدل إعادة
استضافة الأوزان. لا تُملأ ذاكرة نماذج أبدًا. الحمولات البعيدة بيانات وصفية
فقط بسقوف صارمة. تثبت اختبارات الانحدار أن أنظمة البنية والذاكرة لا تستدعي
مُنزِّلات الأوزان. أي تنزيل وزن فشل تلقائي للمرحلة ما لم يُعالَج بالكامل.
