# منهجية أمان جلب البيانات الوصفية

> المقابل الإنجليزي: `docs/en/methodology/metadata-fetch-security.md`

## انضباط القائمة البيضاء

تُجلب فقط ملفات البيانات الصغيرة العامة من مضيفين مسموحين، ولا تُدرج
امتدادات الأوزان أبدًا. كل عنوان يجتاز حارس SSRF قبل التوجيه وبعده: المضيف
المحلي والعناوين الخاصة والمموهة عدديًا وبروتوكول الملفات وبيانات الاعتماد
المضمنة وأهداف التوجيه غير الآمنة كلها مرفوضة.

## الحدود

سقف المستند 256 KiB، والطلبات GET فقط بمهلات قصيرة، وميزانية لكل تشغيل تحد
عدد الطلبات. الحمولات الزائدة وJSON المشوه وأنواع المحتوى غير المتوقعة
مرفوضة بأخطاء صريحة. يُحلَّل JSON كبيانات فقط دون تنفيذ.

## المصادقة

كل الوصول مجهول (`token=False`)؛ لا تُقرأ رموز مخزنة ولا تُستخدم جلسات
موثقة ولا تُلاحَق النماذج المقيدة. الجلب متسلسل بأعداد منخفضة دون زحف.
