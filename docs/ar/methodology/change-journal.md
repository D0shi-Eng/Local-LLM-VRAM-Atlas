# سجل التغييرات (المرحلة الخامسة)

إلحاقي فقط ومقروء آليًا (`catalog/changes/change-journal.jsonl`، حدث مضغوط
في كل سطر). الأحداث التاريخية لا تُعاد كتابتها للتظاهر بعدم وقوعها؛
التصحيحات أحداث لاحقة ناسخة.

كل حدث: معرف مضغوط حتمي (`chg-v1-<sha256>` دون عيب الطول)، نسخة الحدث،
النوع، الخطورة، النموذج، القطعة والمصدر عند الحاجة، المراجعتان القديمة
والجديدة، البصمتان، الحقول المتغيرة، الأدلة، وقت الكشف، حالة المراجعة
والتطبيق، وملاحظات. تُحال الهويات والحقول دون تكرار سجلات كاملة.

لا إزعاج بلا تغيير: نفس المراجعة والحالة والقطع يعني لا حدث (الملخص يقول
"دون تغيير"). تغير الشعبية وحده حدث إعلامي واحد لا يؤهل ولا يغير VRAM.
الإلحاق غير مكرر: إعادة نفس الأحداث لا تضيف شيئًا.
