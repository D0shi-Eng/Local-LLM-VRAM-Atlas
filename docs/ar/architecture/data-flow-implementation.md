# تدفّق البيانات — خط المعالجة المنفَّذ

> المقابل الإنجليزي: `docs/en/architecture/data-flow-implementation.md`

## الحالة

منفذ ومختبَر حيًا على 7 مستودعات حقيقية بتاريخ 2026-10-05. التدفق
المفاهيمي لم يتغير؛ وهذه الوثيقة تسمي الكود الفعلي.

## خط الأنابيب الفعلي

```text
واجهة Hugging Face العامة (مجهول token=False مع مهلة)
        │
        ▼
HuggingFaceSourceClient (قراءة model_info فقط؛ ترجمة الأعطال؛ لا تنزيل أبدًا)
        │
        ▼
DTO البيانات الخام (مستقل عن SDK؛ والمعرف الأصلي محفوظ)
        │
        ▼
المطبّع
        │
        ├── محلل الترخيص
        ├── محلل النسب
        ├── مصنف الملفات (استدلال أسماء فقط) + حارس الأوزان
        └── باني النسب (سجل مصدر واحد + 9 سجلات دليل)
        │
        ▼
السجل المعياري (دون كتلة VRAM في هذه السجل)
        │
        ▼
التحقق من مخطط JSON
        │
        ▼
الحفظ الذري (ملف مؤقت ثم استبدال)
        │
        ▼
catalog/models + catalog/sources + catalog/evidence (+ لقطات التدقيق)
```

أمور شاملة: حارس العناوين (بما فيه التمويه العددي)، ومساعد GiB الموحد،
وتصنيف الأعطال، وسجل المصادر (9 قيود)، والواجهة (فحص/استقبال/تحقق/مصادر).
