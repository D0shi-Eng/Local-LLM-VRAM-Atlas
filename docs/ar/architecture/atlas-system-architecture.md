# معمارية نظام الأطلس

> المقابل الإنجليزي: [`docs/en/architecture/atlas-system-architecture.md`](../../en/architecture/atlas-system-architecture.md)
>
> المخططات معروضة في الوثيقة الإنجليزية عن قصد، لوضوح المصطلحات الهندسية.
> ولكل شكل شرح عربي في [فهرس الأشكال](../../diagrams/README.md).

## الغرض

تصف هذه الوثيقة تركيب الأطلس: مسؤولية كل طبقة، وما الذي امتنع عنه التزامًا،
وكيف تتركّب الطبقات في خط معالجة واحد لا يحمل إلا البيانات الوصفية.

الأطلس **يعتمد على البيانات الوصفية وحدها**. يقرأ بيانات وصفية ووثائق منشورة،
ثم يحوّلها إلى سجلات قانونية مُحقَّقة ضد مخططات، ثم يشتق منها تقديرات ذاكرة
واعية ببنية النموذج وحالة أدلة الجودة، ثم يولّد عروضًا ثنائية اللغة. وهو لا
ينزّل أوزان النماذج، ولا يشغّل أي نموذج، ولا يُسجّل الدخول في أي خدمة.

## مسؤوليات الطبقات

| الطبقة | المسؤولية | ما لا تفعله |
|---|---|---|
| المصادر الخارجية | قراءة البيانات الوصفية والوثائق المنشورة | المصادقة، والرفع، وتنزيل الأوزان |
| الاستقبال | تطبيع البيانات الخام إلى سجلات قانونية تحمل النسب | اختراع قيمة لم يصرّح بها المصدر |
| التحليل البنيوي | استخراج شكل البنية ودلالات التكميم من البيانات الوصفية | تخمين بُعدٍّ مفقود من الأبعاد |
| التحليل الحوسبي | إنتاج **مدى** للذاكرة مع حالة دليل صريحة | تحويل المدى إلى حكم «يناسب» غير صحيح |
| ذكاء الجودة | إرفاق نتائج التقييم بالمُخرج بعينه الذي قِيست عليه | نقل درجة النموذج الأساسي إلى مشتق مكمَّم |
| إغلاق الأدلة | إعادة استحواذ النسب الحالية وقرار جاهزية النشر | تخفيض بوابة لإنتاج عدد غير صفري |
| التحديث التدريجي | كشف تغيّر المصدر وتطبيقه بمعاملة ذرّية | إعادة كتابة سجلات قانونية لم تتغيّر |
| الكتالوج القانوني | مصدر الحقيقة الوحيد، بصيغة قابلة للقراءة آليًا | الاعتماد على نثر مولَّد |
| العروض | صفحات Markdown وJSON ثنائية اللغة مولَّدة من السجلات | التعديل اليدوي |

## الحدود الأمنية

يفرض الأطلس حدّين أمنيين يظهران في الشيفرة نفسها لا في وثيقة سياسة:

1. **لا بيانات اعتماد، إطلاقًا.** يرفض الملفان `metadata_fetch.py` و
   `url_safety.py` قراءة أي رمز مصادقة أو تخزينه أو إرساله. والوضع الوحيد
   المسموح به هو القراءة العامة المجهولة.
2. **لا حمولات أوزان.** تُرفض الروابط المتجهة إلى ملفات أوزان **قبل** إجراء
   الطلب، ولا تُتبع إعادة التوجيه، ولكل عملية استحواذ سقفٌ مُعلَن للطلبات
   وسقفٌ مُعلَن للبايتات، ويُطبَّق السقفان وقت التشغيل.

التفاصيل: [أمن جلب البيانات الوصفية](../methodology/metadata-fetch-security.md).

## ثوابت التصميم

1. **المخططات هي العقد.** كل سجل قانوني يُحقَّق ضد مخطط JSON مُصدَّر بإصدار، قبل
   أن يُسمح بكتابته.
2. **الكتالوج قانوني والتوثيق مولَّد.** لا يصبح النثر مصدرَ الحقيقة أبدًا.
3. **الغياب قيمة أساسية.** حالا `unknown` و`unsupported` و`insufficient_evidence`
   قيم مسجَّلة، لا ثغرات تُملأ بالتقدير.
4. **الأداة تعمل في وضع تجريبي افتراضيًا.** كل أمر مُعدِّل يتطلب `--apply` صريحًا.
5. **الدليل لا يُورَّث.** الدرجة المقيسة على إصدار أساسي لا تنتقل إلى مشتق مكمَّم،
   ولا تنتقل إلى متغيّر معدَّل المحاذاة.
6. **غياب نطاق دليل يخفض الحالة، ولا يرفعها أبدًا.**

## خريطة الحزم

| الحزمة | المجال |
|---|---|
| `atlas.intake` | محوّلات المصدر، والتطبيع، والنسب، وتصنيف التراخيص، وحُرّاس الروابط والأوزان |
| `atlas.archinfo` | حل البنية من ملف الإعداد وبيانات GGUF، ومخطط الطبقات المعياري |
| `atlas.quant` | سجل التكميم مُصدَّر الإصدار، وحساب البتات لكل وزن |
| `atlas.artifact` | تجميع الملفات في مجموعات مُخرجات، وكشف المكوّنات المرافقة |
| `atlas.memory` | بايتات الأوزان، وبايتات ذاكرة KV، والأعباء الساكنة والديناميكية، وتقدير المدى |
| `atlas.vram` | التصنيف بالمدى لفئات 4 و8 و12 و16 غيغابايت |
| `atlas.runtimes` | قاعدة معرفة بيئات التشغيل، مشتقة من التوثيق وحده |
| `atlas.measurements` | سجل القياسات الخارجية؛ يتحقق من القياسات ولا ينتجها |
| `atlas.quality` | استيعاب التقييمات، وملفات الجودة، وقابلية المقارنة، والاحتفاظ، وجاهزية التوصيات |
| `atlas.catalog` | تجميع الكتالوج القانوني، والهوية، والتأهيل، والتصنيف، وتوليد العروض |
| `atlas.refresh` | البصمات، والاكتشاف، والتخطيط، والتطبيق الذرّي، ويوم التغييرات |
| `atlas.closure` | مجموعة التوصيات الأساسية، وإعادة استحواذ الأدلة الحالية، وأدلة الذاكرة، وجاهزية النشر |
| `atlas.external` | استحواذ خارجي محدود، وفحص محلي لبيئة تشغيل قائمة سلفًا |
| `atlas.security` | فرض سياسة الشبكة |
| `atlas.validation` | التحقق ضد المخططات، وأداة سطر الأوامر |
| `atlas.cli` | سطح الأوامر، تجريبي افتراضيًا |
