# الفهرس (Catalog)

> **English version:** [README.md](README.md)

**الحالة:** مجموعة بيانات منتقاة بالبيانات الوصفية وحدها — 34 إصدار نموذج، و201
متغيّر مُخرَج مكمَّم، و109 سجل دليل. ليست قاعدة بيانات كاملة، وليست ترتيبًا.

يضم هذا المجلد الكتالوج القانوني المقروء آليًا:

| المسار | المحتوى | المخطط |
|---|---|---|
| `manifest.json` | الأعداد ومعرّفات النماذج وإصدارات المخططات | — |
| `models/` | سجلات النماذج، ملف لكل إصدار | `model.schema.json` |
| `artifacts/` | متغيّرات المُخرجات المكمَّمة، ملف لكل متغيّر | `artifact.schema.json` |
| `sources/` | سجل المصادر ورصد كل مصدر | `source.schema.json` |
| `evidence/` | مرافق الأدلة، سجل لكل حقل | `evidence.schema.json` |
| `benchmarks/evaluations/` | نتائج المقاييس بهوية أدوات كاملة | `evaluation-result.schema.json` |
| `measurements/` | ملاحظات ذاكرة رسومية مُبلَّغ عنها خارجيًا | `measurement.schema.json` |
| `quality/` | الملفات وسجلات الاحتفاظ وفجوات الأدلة والبيان | `quality-profile.schema.json` و`quant-retention.schema.json` |
| `closure/` | مجموعة التوصيات الأساسية وأدلة الذاكرة والجاهزية | — |
| `snapshots/` | لقطات البيانات الوصفية العامة الخام (مدخلات تدقيق، **ليست** سجلات معيارية ولا تخضع لتحقق المخطط) | — |
| `runtimes/` | محجوز لسجلات بيئات التشغيل، وفارغ الآن بقصد | `runtime.schema.json` |
| `views/` | عروض ثنائية اللغة مولَّدة بصيغتي Markdown وJSON | — |

## القواعد

- سجلات JSON المحقَّقة عبر JSON Schema هي مصدر الحقيقة الوحيد.
- لا يُخزَّن أي وزن نموذج هنا إطلاقًا.
- لا يجوز لأي سجل أن يعلن حالة `verified` أو `recommended` دون النسب الموثَّق
  الذي تشترطه [سياسة الأدلة](../docs/ar/governance/evidence-policy.md).
- لا يُعامل حجم الملف أبدًا باعتباره استهلاك VRAM.
- الحقل الغائب يعني «غير معروف»، ولا يُملأ بالتقدير أبدًا.

## التغطية

الكتالوج **مجموعة منتقاة**، لا فهرس شامل للنماذج المحلية. وثلاثة نطاقات من الأدلة
تبقى غير محلولة عبر الإصدارات المفهرسة: أدلة الجودة العربية، وأدلة الملاءمة
للذاكرة الرسومية، وأدلة الجودة المستقلة متعددة المصادر. ونتيجة ذلك أن المشروع
**يُبلّغ عن صفر توصيات صارمة** عند 4 و8 و12 و16 غيغابايت.

وهذه نتيجة أدلة، لا ميزة غير مكتملة. انظر
[جاهزية التوصيات](../docs/ar/workflows/recommendation-readiness.md) للبوابات
المعيقة بالاسم.

## المُخرَج المولَّد

كل ما تحت `views/` مولَّد من السجلات القانونية عبر خط المعالجة نفسه الذي ينتج
اللغتين من حمولة واحدة. لا تُعدِّل العرض المولَّد يدويًا: فإعادة التوليد التالية
تطمسه.

## المسارات المستبعَدة

تحتوي `refresh/` و`checkpoints/` و`changes/` على حالة تشغيل متقلبة ويوم تشغيل.
تُعاد ولادتها عند الحاجة، وليست جزءًا من المستودع المنشور.
