# الفهرس (Catalog)

> **English version:** [README.md](README.md)

**الحالة:** بيانات بذور المرحلة الأولى فقط — 7 سجلات استقبال حقيقية تثبت
خط الأنابيب (6 بذور هندسية + مشتق واحد من طرف ثالث). ليست قاعدة بيانات
كاملة وليست ترتيبًا.

سيضم هذا المجلد مستقبلًا فهرس الأطلس المقروء آليًا:

- `models/` — سجلات النماذج المطابقة لـ`schemas/model.schema.json`.
- `sources/` — سجلات المصادر المطابقة لـ`schemas/source.schema.json`
  (ومنها `registry.json` قائمة المصادر الموثوقة).
- `evidence/` — سجلات الأدلة المطابقة لـ`schemas/evidence.schema.json`،
  واحد لكل حقل حساس، مربوطة من سجلات النماذج عبر `evidence_ids`.
- `snapshots/` — لقطات البيانات الوصفية العامة الخام (مدخلات تدقيق، ليست
  سجلات معيارية ولا تخضع لتحقق المخطط؛ وتُظهر ما قاله المصدر حرفيًا).
- `runtimes/` — سجلات توافق بيئات التشغيل المطابقة لـ`schemas/runtime.schema.json`.
- `benchmarks/` — سجلات القياسات المطابقة لـ`schemas/benchmark.schema.json`.

القواعد:

- سجلات JSON المحققة عبر JSON Schema هي المصدر الوحيد للحقيقة.
- يُمنع تخزين أوزان النماذج هنا إطلاقًا (انظر سياسة الأمن).
- يُمنع أي سجل من ادعاء حالة `verified` أو `recommended` دون النسب الموثق الذي
  تشترطه سياسة الأدلة.
- لا يُعامل حجم الملف أبدًا باعتباره استهلاك VRAM.
