# مجموعة الاختبارات

> المقابل الإنجليزي: [`README.md`](README.md)

شجرة `tests/` مرتَّبة حسب **المجال الهندسي**، لا حسب ترتيب بناء المشروع. وأسماء
المجلدات تصف ما تفعله الشيفرة، فيستطيع قارئ لم يسبق له الاطلاع على هذا
المستودع أن يستنتج المعمارية من بنية الاختبارات وحدها.

## تشغيل المجموعة

```bash
python -m pytest -q
```

المجموعة **تعمل دون اتصال بالكامل افتراضيًا**. ولا يُجري أي اختبار في التشغيل
الافتراضي طلبًا شبكيًا، ولا يبدأ خادمًا، ولا ينزّل نموذجًا، ولا يكتب في الكتالوج
القانوني.

## الاختبارات الحيّة

الاختبارات التي تتصل بخادم Hugging Face العام اختيارية موسومة بـ`live`:

```bash
python -m pytest -q -m live
ATLAS_LIVE=1 python -m pytest -q -m live
```

وهي تقرأ **البيانات الوصفية العامة فقط**. ولا تنزّل أوزانًا ولا تصدّق.

## سياسة البيانات التركيبية

يحتوي `fixtures/valid/` على سجلات تركيبية **يجب** أن تجتاز التحقق، ويحتوي
`fixtures/invalid/` على سجلات **يجب** أن تفشل، كلٌّ منها بسبب موثَّق واحد. وكل اسم
ملف بيانات يحمل `fixture-` حتى لا يظنها أحد بيانات فهرس حقيقية.

وجميع البيانات تركيبية بالكامل. ولا يحتوي أي ملف بيانات على اعتماد حقيقي، ولا
مسار خاص حقيقي، ولا بيانات شخصية حقيقية.

### ملف البيانات الوحيد الشبيه بالأسرار

يتضمّن `fixtures/invalid/fixture-secret-like.txt` عمدًا نصًا مصطنعًا على هيئة رمز
وصول. ويصرّح ترويسة الملف نفسه بأنه تركيبي، وأنه لا يمنح أي صلاحية، وأن وجوده
ليثبت أن أداة كشف الأسرار تلتقط النمط دون أن يسرّبه. وهو الملف الوحيد المستثنى
ضمن مسح الأسرار.

## ضمان انعدام الأوزان

لا يجوز لأي اختبار أن يحمّل نموذجًا أو ينزّله أو يشير إلى ملف أوزان. ويحتوي مجلد
`security/` على حرّاس ثابتة ترفض إدخال أداة تنزيل أو محمِّل إلى `src/`، ويفشل
`security/test_no_weight_files.py` إن ظهر امتداد أوزان في الشجرة.

## البانيات المشتركة

يوفّر `builders/candidates.py` و`builders/records.py` سجلات تركيبية — مرشَّحين،
وسجلات نماذج، وقياسات، وتقييمات، وحقول بنية — تُعاد استخدامها في المجالات
التي تحتاجها. وسبب وجودها ألّا يخترع مجالان شكلين غير متوافقين للنوع نفسه من
السجل.

## إضافة اختبار

1. ضعه في المجلد المخصَّص للمجال الذي يمارسه. وإن لم يناسب أي مجلد، فأضف مجلدًا
   وسمِّه باسم النظام الفرعي، لا باسم محطة إنجاز.
2. سمِّ الملف بالمسؤولية، لا باسم الوحدة المختبَرة وحدها:
   `test_recommendation_readiness.py`، لا `test_phase6.py`.
3. اكتب التصدير بلغة المجال: «سلوك التحديث التدريجي»، لا «ما أضافته المرحلة
   الخامسة».
4. أبقِه دون اتصال. وإن احتاج فعلًا إلى الخادم العام، فوسمه بـ`live`.
5. استخدم `builders/` بدل اختراع شكل ثانٍ لنوع سجل.
